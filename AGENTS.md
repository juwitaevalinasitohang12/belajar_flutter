# AGENTS.md

## Deskripsi Project

Project ini merupakan aplikasi Flutter untuk latihan pembelajaran
Flutter dan penggunaan Git/GitHub.

## Struktur Project

- `lib/` berisi kode utama aplikasi.
- `lib/main.dart` merupakan file utama aplikasi.
- `test/` berisi file pengujian.
- `android/` berisi konfigurasi Android.
- `ios/` berisi konfigurasi iOS.
- `web/` berisi konfigurasi Web.

## Aturan Pengembangan

1. Gunakan format kode Dart yang rapi.
2. Jalankan `dart format .` setelah melakukan perubahan kode.
3. Jalankan `flutter analyze` untuk memeriksa masalah pada kode.
4. Gunakan pesan commit dengan format konvensional.
5. Jangan mengubah file konfigurasi penting tanpa alasan.
